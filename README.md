# Tip Time

Tip Time is a simple Android application developed as a practice project while learning Android development using **Kotlin** and **XML**.

The application calculates the tip amount based on the bill amount and the selected tip percentage.

## Features

- Enter the bill amount.
- Select the tip percentage.
- Calculate the tip amount.
- Display the calculated tip.
- Simple and user-friendly interface.

## Technologies Used

- Kotlin
- XML
- Android Studio
- Android SDK

## Concepts Practiced

Through this project, I practiced:

- Building Android layouts using XML.
- Connecting XML views with Kotlin code.
- Handling user input.
- Working with `EditText`, `TextView`, and `Button`.
- Using click listeners.
- Performing calculations using Kotlin.
- Updating UI elements dynamically.
- Understanding the basic Android project structure.
